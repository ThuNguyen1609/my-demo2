1. Git init: khởi tạo repo ở local
-> các file được add mới/sửa sẽ xuất hiện ở vùng directory

2. Git add <file name>
-> thêm file X vào vùng staging area

3. git add .
-> thêm tất cả các file ở repo hiện tại vào vùng staging area

4. Git commit -m "message"
-> chốt các thay đổi vừa add và gán nhãn tên là message (chốt version)
